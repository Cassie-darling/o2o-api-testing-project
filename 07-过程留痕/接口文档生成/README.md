# 过程留痕：接口文档生成中间件

接口文档生成过程中的分段草稿与合并产物，归档以备追溯。

| 文件 | 说明 |
|---|---|
| `draft.xml` | 接口文档第一段草稿 |
| `part2.xml` | 接口文档第二段草稿 |
| `part3.xml` | 接口文档第三段草稿 |
| `full.xml` | 三段合并后的接口文档终稿 |
| `merge.py` | 合并脚本，按 `draft → part2 → part3` 顺序拼接生成 `full.xml` |
| `.presentation-decision.json` | 生成时的呈现与受众决策记录（读者：O2O 测试站的接口测试人员） |

注：`merge.py` 中 `base` 为原始工作目录绝对路径，仅作留痕，重新执行前需修改为该目录的实际路径。
