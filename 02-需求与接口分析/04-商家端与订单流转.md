# 4. 商家端与订单流转链路（入驻 / 商品 / 配送 / 接单 / 订单查询）

> 商家端控制器实际挂在 home 模块下：`/index.php/home/seller{控制器}/{方法}.html`（不是 /seller/）。
> 商家登录会话与买家会员会话相互独立但同域 Cookie；**切换买家/卖家身份前必须先 logout，否则会出现“不能购买自己店铺的商品”“所购商品无效”等串号问题**。

## 4.1 商家登录 / 退出
- 登录：`POST /index.php/home/sellerlogin/login.html`（form-urlencoded）
  - Body：`seller_name`（卖家账号，非会员名）、`member_password`
  - 成功为 dispatch_jump 跳转商家中心（无 JSON 包裹）；账号/密码错误为错误页。
- 退出：`GET /index.php/home/sellerlogin/logout.html`
- 商家中心：`GET /index.php/home/seller/index.html`
- 用例要点：卖家账号与会员账号区分、停用/审核中卖家登录、未登录访问 seller 控制器。

## 4.2 个人商家入驻（C2C，4 步向导，实测创建店铺15）
- 入口（个人入驻）：`GET /index.php/home/Sellerjoininc2c/step1.html`（企业入驻为 sellerjoinin）。
- Step1 店铺资质 → `POST /index.php/home/sellerjoininc2c/step2.html`：

| 参数 | 必填 | 说明 |
|---|---|---|
| company_name | 是 | 店铺/主体名称 |
| company_address / province_id / city_id / district_id / company_address_detail | 是 | 地区与详细地址（province_id=22,city_id=62,district_id=352） |
| longitude / latitude | 是 | **坐标随此步写入，之后商家端无坐标编辑入口**（重庆南岸 106.559476,29.556933） |
| contacts_name / contacts_phone / contacts_email | 是 | 联系人/手机/邮箱 |
| business_licence_number | 是 | **个人入驻也强制必填**，18 位统一社会信用代码（测试用 91500108MA5TEST001） |
| business_licence_address / business_licence_start / business_licence_end | 是 | 执照地址/有效期（YYYY-MM-DD） |
| business_sphere | 否 | 经营范围 |

  - 未填执照号 → dispatch_jump“营业执照号不能为空”。
- Step2 财务资质 → `POST /index.php/home/sellerjoininc2c/step3.html`：
  - `settlement_bank_account_name`（开户名）、`settlement_bank_account_number`（银行账号）。
- Step3 店铺经营信息 → `POST /index.php/home/sellerjoininc2c/step4.html`：

| 参数 | 说明 |
|---|---|
| seller_name | 卖家登录账号（如 testojoins） |
| store_name | 店铺名称（如 O2O南岸测试餐厅） |
| storegrade_id | 店铺等级：1 系统默认 / 2 白金 / 3 钻石 |
| joinin_year | 入驻年限：1 / 2 |
| storeclass_id | 店铺分类：1 蛋糕甜点 / 2 自助餐 / 3 小吃快餐 / 4 火锅 / 5 西餐 / 6 麻辣烫 / 7 水果生鲜 / 8 果汁饮品（括号内为保证金，多为 0） |
| store_class | 经营类目末级 gc_id（隐藏域，由 gcategory_class1 联动选择），水果生鲜=7（无下级，即末级） |

  - 提交后直接提示“入驻申请已经提交，请等待管理员审核”（保证金 0 时无缴费步骤）。
- 入驻页百度地图 ak 无效会弹 alert **冻结页面 JS**；自动化时改用页面内 fetch 取表单，勿走地图选点。
- 用例要点：必填缺失、执照号格式/长度、坐标缺失、店铺名/卖家账号重复、类目层级未选到末级、保证金类目、重复入驻。

## 4.3 平台后台审核开店
- 开店申请列表：`GET /index.php/admin/store/store_joinin.html`（状态：新申请/已付款/待付款/审核失败/开店成功/取消）。
- 审核详情：`GET /index.php/admin/store/store_joinin_detail.html?member_id={入驻会员id}`
- 提交审核：`POST /index.php/admin/store/store_joinin_verify.html`（form `#form_store_verify`）：

| 参数 | 说明 |
|---|---|
| verify_type | `pass` 通过 / `fail` 拒绝（点按钮写入，非 1/0） |
| member_id | 入驻会员ID（testojoin=163） |
| paying_amount | 缴费/保证金金额（保证金 0 类目传 0） |
| joinin_message | 审核意见 |

  - 通过返回 `<script>parent.layer.alert('店铺开店成功',...)</script>`；通过后店铺有效期默认 +1 年（店铺15 至 2027-09-20）。
  - 通过前会校验经营类目分佣比例 `commis_rate`（0–100，缺失则拦截）；无绑定类目时该校验跳过。
- 经营类目绑定（后台代绑）：列表 `GET /admin/store/store_bind_class.html?store_id={id}`；新增 `POST /admin/store/store_bind_class_add.html`，Body `store_id`、`goods_class`(gc_id，如 7)、`commis_rate`(0–100 整数)。
- 用例要点：重复审核、拒绝后能否重新申请、分佣比例边界（0/100/101/空/负数）、审核通过后店铺状态/有效期、类目绑定后商品分类才可选（绑定后建议清缓存）。

## 4.4 商家商品发布（4 步向导，实测创建商品79）
- 向导：STEP1 选分类 → STEP2 填详情 → STEP3 传图 → STEP4 成功。
- 选分类（逐级 AJAX）：`GET /index.php/home/Sellergoodsadd/ajax_goods_class.html?gc_id={父gc_id}&deep={层级}`
  - 返回该级子分类数组 `[{gc_id,gc_name,type_id}]`，末级返回 `[]`。
  - 注意：店铺未绑定经营类目时 `gc_id=0&deep=1` 返回 `[]`（先按 4.3 绑类目并清缓存）。
- 可绕过分类向导直接进详情页：`GET /index.php/home/sellergoodsadd/add_step_two.html?class_id={末级gc_id}`（实测 class_id=7 直接出表单）。
- 保存商品：`POST /index.php/home/sellergoodsadd/save_goods.html`（form-urlencoded 即可，图片非第二步必填），主要字段：

| 参数 | 必填 | 说明 |
|---|---|---|
| commonid | 否 | 空=新增；编辑时传商品公共ID |
| type_id | 是 | 商品类型，无则 0 |
| cate_id / cate_name | 是 | 末级分类ID/名（隐藏域，7/水果生鲜） |
| g_name | 是 | 商品名称 |
| g_jingle | 否 | 广告词/副标题 |
| g_price | 是 | 售价（25.00） |
| g_marketprice / g_costprice | 否 | 市场价/成本价 |
| g_storage | 是 | 库存 |
| g_alarm | 否 | 库存预警 |
| g_serial | 否 | 货号 |
| goods_body / m_body | 否 | PC/移动端详情（富文本） |
| image_path / goods_image | 否 | 图片路径/上传文件（第三步可补传） |
| sgcate_id[] | 否 | 店内分类ID，0=不选 |
| g_state | 是 | 1=立即出售（上架），0=放入仓库 |
| g_vat | 否 | 是否支持增值税发票 0/1 |
| g_commend | 否 | 是否推荐 0/1 |
| starttime / starttime_H / starttime_i | 否 | 上架时间 |
| plate_top / plate_bottom | 否 | 顶部/底部关联版式 |

  - 成功：302/跳转 `add_step_three/commonid/{commonid}.html`（实测 commonid=79，单规格商品 goods_id=commonid）。
  - g_state=1 上架后**无需平台审核**，立即出现在商家“出售中商品”、店铺页与附近商家 goods_list。
- 商品管理：出售中 `GET /home/sellergoodsonline/index.html`、仓库中 `GET /home/sellergoodsoffline/index.html`、商品规格 `/home/sellerspec/index.html`。
- 用例要点：价格负数/0/超大、库存负数/非数字、必填缺失、上下架状态对买家可见性、商品名长度/特殊字符、多规格 SKU 价格库存、改价后购物车/结算金额。

## 4.5 店铺外卖（O2O）配送设置
- 页面/提交：`GET|POST /index.php/home/seller_o2o/index.html`（form-urlencoded，JSON 返回 `{code:10000,message:"保存成功"}`）：

| 参数 | 说明 |
|---|---|
| store_o2o_open | 是否开启外卖（页面中该单选被注释，固定不可编辑，由入驻/后台决定） |
| store_o2o_receipt | 是否接单（1 是 / 0 否） |
| store_o2o_distribute_type | 配送方式：1=店铺自配送（本环境仅渲染此项；平台配送需后台开通且有覆盖该区域的平台配送员） |
| store_o2o_auto_receipt | 自动接单 1/0 |
| store_o2o_auto_deliver | 自动派单 1/0（无配送员时开启会触发派单字段写入问题，见 03 的 3.8.2） |
| store_o2o_open_time | 营业时间段，分钟数组，如 `480,1080`=08:00-18:00 |
| store_o2o_distance | 配送距离（米），如 5000 |
| store_o2o_fee | 配送费（元），如 2.00 |
| store_o2o_min_cost | 起送价 |
| store_o2o_complaint_fine | 投诉罚款 |
| store_o2o_receipt_limit / store_o2o_reject_time | 接单上限/拒单时长 |

- 用例要点：配送距离 0/负数/超大、配送费边界、营业时间跨天/颠倒、歇业(receipt=0)时能否下单、起送价校验。

## 4.6 配送员管理
### 商家配送员（⚠️ 本环境有缺陷）
- 列表：`GET /index.php/home/seller_o2o_distributor/index.html`
- 新增：`GET|POST /index.php/home/seller_o2o_distributor/add.html`
  - 字段：o2o_distributor_name（账号）、o2o_distributor_password、o2o_distributor_realname（真实姓名）、o2o_distributor_phone、o2o_distributor_email、remark、introduce、o2o_distributor_state（单选 1 是/0 否，默认 1）、头像文件 o2o_distributor_avatar。
  - **实测缺陷（可复现）**：无论 GET/POST、urlencoded/multipart、state 传 0/1/数组、放 query 还是 body，官方 ds_ajaxpost 序列化（确认含 `o2o_distributor_state=1`）提交后均返回 `{"code":10001,"message":"请选择状态","result":""}`——服务端未正确接收该校验字段，商家端无法新增配送员。
### 平台配送员（后台，接口正常）
- 列表：`GET /index.php/admin/o2o_distributor/index.html`（`?verify=1` 待审核）
- 新增：`POST /index.php/admin/o2o_distributor/add.html`（成功返回 layer.alert“保存成功”）；编辑：`/admin/o2o_distributor/edit.html?id={id}`。
  - 字段同商家端，另有 `o2o_distributor_region_id/o2o_distributor_region_name`（配送地区，城市/区县ID）、`o2o_distributor_errand_deposit`（跑腿押金，默认500）、`store_id`（**传 store_id 可为指定店铺建配送员**，不传=平台级 store_id=0）、state 默认 1。
- 平台配送设置：`GET|POST /index.php/admin/o2o/setting.html`（o2o_socket_url、o2o_distance、o2o_auto_distribute 自动派单、o2o_fee、o2o_complaint_fine）。
- 配送员结算：商家 `/home/seller_o2o_order_bill/index.html`、平台 `/admin/o2o_order_bill/index.html`；投诉：seller_o2o_complaint / admin o2o_complaint。
- 用例要点：配送员账号重复、手机号格式、启停后派单、配送地区与订单区域匹配、押金边界（接口缺陷本身作为缺陷用例）。

## 4.7 买家订单查询与操作（路由 + 错误态已实测；成功态受下单缺陷阻断）
- 订单列表（按状态 Tab，GET，服务端渲染）：`GET /index.php/home/memberorder/index/state_type/{state}.html`
  - state 取值：`state_new` 待付款、`state_pay` 待接单/待发货、`state_send` 待收货、`state_success` 已完成、`state_noeval` 待评价、`state_cancel` 已取消；回收站 `/home/memberorder/index/recycle/1.html`。
  - 空结果返回页面（无订单行）；数据查 `ds_order` 表按 buyer_id + delete_state=0。
- 订单详情：`GET /index.php/home/memberorder/show_order/order_id/{id}.html`
  - 不存在订单：dispatch_jump“该订单不存在”。
- 订单状态变更（取消/确认收货统一入口）：`/index.php/home/memberorder/change_state.html`（GET/POST，参数 order_id + 目标状态；无订单时返回空 200，具体状态键需待有订单后从订单行按钮确认）。
- 我的评价：`GET /index.php/home/memberevaluate/index.html`；退款/售后：`GET /index.php/home/memberrefund/index.html`（具体提交表单需进入真实订单详情页抓取，当前无订单未取得）。
- 用例要点：越权查看/操作他人 order_id（核心安全）、各状态机非法跃迁（如未付款直接确认收货）、重复取消/重复确认、取消后库存与优惠券回滚、回收站还原。

## 4.8 商家订单处理（路由 + 错误态已实测）
- 订单列表（按状态 Tab）：`GET /index.php/home/sellerorder/index/state_type/{state}.html`
  - state：state_new 待付款、state_pay 待接单、state_pick 待备货/取货、state_send 配送中、state_success 已完成、state_cancel 已取消。
- 订单详情：`GET /index.php/home/sellerorder/show_order/order_id/{id}.html`（不存在→“该订单不存在”）。
- 商家接单：`GET|POST /index.php/home/sellerorder/receipt_order.html`，参数 `order_id`
  - 实测返回 JSON：订单不存在 → `{"code":10001,"message":"该订单不存在","result":""}`。
- 商家拒单：`/index.php/home/sellerorder/reject_order.html`（order_id + 拒单原因，字段待真实订单确认）。
- 自提核销码校验：`GET /index.php/home/sellerorder/check_o2o_order_pickup_code.html`，参数取货码
  - 实测空参 → `{"code":10001,"message":"取货码不能为空","result":""}`。
- 商家评价管理：`/home/sellerevaluate/index.html`；商家结算账单：`/home/sellerbill/index.html`。
- 用例要点：重复接单、拒单后退款/库存回滚、接单状态机、核销码错误/已使用、并发接单、越权操作他店订单。

## 4.9 平台后台交易管理（路由）
- 实物/外卖订单：`GET /index.php/admin/Order/index.html`（openItem `index,Order,trade`，列表 AJAX 分页）。
- 退款管理：`/index.php/admin/Refund/refund_manage.html`。
- 评价管理：`/index.php/admin/Evaluate/evalgoods_list.html`。
- 订单结算：`/index.php/admin/Bill/show_statis.html`；咨询/举报/投诉：admin Consulting/Inform/Complain。
- 用例要点：后台代客退款金额校验、强制关闭订单、评价审核/删除、跨店订单与配送员分账。
