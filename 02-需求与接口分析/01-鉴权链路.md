> 系统：德尚 DS·O2O 外卖版（ThinkPHP 传统 MPA + AJAX 混合）
> 前台：http://o2o.project.hctestedu.com/Home/Index/index.html
> 后台：http://o2o.project.hctestedu.com/admin/index/index.html （admin / admin123）
> 测试买家账号：testo2o1943 / 123456（真实注册）

## 0. 通用约定（测试必读）

### 0.1 基础地址与路由
- 入口根：`http://o2o.project.hctestedu.com/index.php`
- 买家端：`/index.php/home/{控制器}/{方法}.html`
- 商家端：`/index.php/seller/{控制器}/{方法}.html`
- 平台后台：`/index.php/admin/{控制器}/{方法}.html`
- 伪静态后缀 `.html` 可省略；大小写路由不敏感（框架做了小写转换）。

### 0.2 鉴权方式
- 基于 Cookie-Session（PHPSESSID），登录成功后服务端 Set-Cookie，后续请求自动携带。
- 无独立 token/Authorization 头。
- 未登录访问需鉴权接口：跳转登录页（页面类）或返回未登录 JSON（AJAX 类）。

### 0.3 三类响应形态（断言要点）
1. **AJAX JSON**（下单、登录、增删改等异步操作）：
   ```json
   {"code":10000,"message":"登录成功","result":""}
   ```
   - `code=10000` 成功；`code=10001` 业务失败（其余错误码见各接口）。
   - `message` 为提示语；`result` 为数据或跳转 URL。
2. **表单跳转页 dispatch_jump**（传统 form POST）：
   - HTML 中含 `<div class="system-message">`，子节点 `.success`/`.error` 表示结果，
     `.detail` 详情，`.jump` 内为“页面自动跳转 等待时间：N 秒”及跳转 `<a href>`（失败常为 `javascript:history.back(-1);`）。
3. **纯文本**（校验类）：`"true"` / `"false"` / 中文错误文案。

### 0.4 测试关注点（通用）
- 登录态过期/未登录、越权访问他人订单、重复提交（幂等）、CSRF/token、参数边界与必填、SQL/XSS 注入位、金额与数量负数/超大值。

## 1. 鉴权链路（注册 / 登录 / 退出 / 找回密码）

### 1.1 用户名可用性校验（注册时远程校验）
- URL：`GET /index.php/home/Login/check_member.html`
- 鉴权：否
- Query：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| member_name | string | 是 | 待校验用户名（表单字段名，前端会同时带） |
| user_name | string | 是 | 同用户名（remote data 字段） |

- 返回：纯文本。`true`=用户名可用（不存在）；`false`=已存在/不可用。
- 实测：admin→`false`；newuser_xyz88→`true`。
- 用例要点：已注册用户名、3/15 字符边界、特殊字符、空值、超长。

### 1.2 会员注册
- URL：`POST /index.php/home/login/register.html`
- Content-Type：`application/x-www-form-urlencoded`
- 鉴权：否（已登录访问会直接 302 到会员中心，不执行注册）
- Body：

| 参数 | 类型 | 必填 | 规则 |
|---|---|---|---|
| member_name | string | 是 | 3-15 位中文/英文/数字/“-”，且远程校验可用 |
| member_password | string | 是 | 6-20 位 |
| member_password_confirm | string | 是 | 与 member_password 一致 |

- 成功：注册后**自动登录**并 302 跳转 `/Home/member/index.html`。
- 失败：dispatch_jump 错误页，实测用户名重复 → `.error` 文案“用户名已存在”，3 秒后 history.back。
- 前端校验：jQuery validate（required/minlength/maxlength/equalTo + remote check_member）；服务端亦有校验。
- 用例要点：重复用户名、用户名边界、密码 5/6/20/21 位、两次密码不一致、空提交、已登录态访问。

### 1.3 会员登录
- URL：`POST /index.php/home/login/login.html`
- 表单 id：`login_normal_form`；无图形验证码
- Body：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| member_name | string | 是 | 用户名/手机号 |
| member_password | string | 是 | 密码 |

- 返回：JSON
  - 成功：`{"code":10000,"message":"登录成功","result":""}`（同时 Set-Cookie 建立会话）
  - 失败（密码错/用户不存在）：`{"code":10001,"message":"账号或密码错误","result":""}`
- 用例要点：错误密码、不存在账号、空值、密码大小写、连续错误（是否有锁定/验证码）、登录后跳转来源页。

### 1.4 退出登录
- URL：`GET /index.php/home/login/logout.html`
- 鉴权：是
- 返回：清除会话后 302 跳转首页 `/home/index/index.html`。
- 用例要点：未登录调用、退出后浏览器后退、退出后受保护接口不可访问。

### 1.5 发送手机短信验证码
- URL：`GET /index.php/home/Connectsms/get_captcha.html`
- 鉴权：否
- Query：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| type | int | 是 | 1=注册 2=登录 3=找回密码 |
| sms_mobile | string | 是 | 11 位手机号 |

- 返回：纯文本。`true`=已发送（前端 60s 倒计时）；否则返回中文错误文案。
- 实测（本站未开启短信功能）：
  - type=1 → “系统没有开启手机注册功能！”
  - type=2 → “系统没有开启手机登录功能”
  - type=3 → “系统没有开启手机找回密码功能”
- 前置条件：后台需开启对应手机功能并配置短信网关。
- 用例要点：非 11 位、非法号段、type 越界值（0/4/空）、60 秒重复发送、同号频控、开关关闭时返回。

### 1.6 校验短信验证码
- URL：`GET /index.php/home/Connectsms/check_captcha.html`
- Query：`sms_mobile`（11 位手机号）、`sms_captcha`（6 位验证码）
- 返回：纯文本。`true`=通过；错误实测返回“验证失败”。

### 1.7 短信找回密码（重置密码）
- URL：`POST /index.php/home/connectsms/find_password.html`
- Body：

| 参数 | 类型 | 必填 | 规则 |
|---|---|---|---|
| sms_mobile | string | 是 | 已注册手机号，11 位数字 |
| sms_captcha | string | 是 | 短信验证码，≥6 位 |
| member_password | string | 是 | 新密码，6-20 位 |

- 前置：手机找回密码功能开启、验证码通过。
- 用例要点：未注册手机号、验证码错误/过期、新密码边界、重置后旧密码失效、新密码可登录。
