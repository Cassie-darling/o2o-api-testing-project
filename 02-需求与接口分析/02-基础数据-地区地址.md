# 2. 基础数据链路（地区联动 / 收货地址）

## 2.1 地区级联数据（省/市/区）
- URL：`GET /index.php/home/Index/json_area.html`
- 鉴权：否
- Query：`src=cache`、`callback=cb`（JSONP，前端固定带 `&callback=?`）
- 返回：JSONP，包裹函数 `cb(...)`，数据结构：
  ```json
  {"0":[[1,"北京"],[2,"天津"],[19,"广东"]...],
   "19":[[199,"广州"],[305,"东莞"]...],
   "305":[[3144,"东莞市"]...]}
  ```
  - key 为父级 area_id（"0"=省级列表），value 为 `[area_id, 名称]` 数组。
  - 一次性下发全量省市区（约 126KB），前端插件 `$.ds_region()` 本地级联。
- 配套回显接口：`GET /index.php/home/Index/json_area_show?area_id={id}&callback=cb`
  - 返回 `cb({"text":" 东莞市"})`（id→名称，编辑回显用）；area_id=0 → `{"text":null}`。
- 测试要点：area_id 越界/非数字/注入、JSONP 回调名自定义、全量数据完整性（台湾/港澳）、缓存头。

## 2.2 收货地址 - 列表（页面，服务端渲染）
- URL：`GET /index.php/home/memberaddress/index/o2o_errand_type/0.html`
  - `o2o_errand_type=0` 收货地址（外卖/实物）；`=1` 发件地址（跑腿代取）。
- 鉴权：是（未登录跳登录）
- 返回：HTML，每条地址含 姓名/地区/详细地址/手机/默认标记/编辑/删除。

## 2.3 收货地址 - 新增
- 表单页：`GET /index.php/home/memberaddress/add/o2o_errand_type/0.html`
- 提交：`POST /index.php/home/memberaddress/add/o2o_errand_type/0.html`
- 鉴权：是；Content-Type：form-urlencoded；AJAX JSON
- Body：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| true_name | string | 是 | 收货人姓名 |
| city_id | int | 是 | 城市ID（东莞=305） |
| area_id | int | 是 | 末级区县ID（东莞市区=3144），需选到最后一级（checklast） |
| area_info | string | 是 | 地区全称，如“广东 东莞市 东莞市” |
| address | string | 是 | 详细地址 |
| tel_phone | string | 否 | 座机 |
| mob_phone | string | 是 | 手机号（11 位） |
| is_default | int | 否 | 1=默认地址 |
| longitude | decimal | 是* | 经度（百度地图选点，外卖配送范围/距离判定用） |
| latitude | decimal | 是* | 纬度 |

- 成功：`{"code":10000,"message":"保存成功","result":{"address_id":"55"}}`
- 测试要点：未选到区、手机号格式、经纬度缺失对配送范围的影响、设为默认后原默认是否取消、同会员地址上限、特殊字符。

## 2.4 收货地址 - 编辑
- 表单页/回填：`GET /index.php/home/memberaddress/edit/address_id/{id}.html`
- 提交：`POST /index.php/home/memberaddress/edit/address_id/{id}.html`（表单 action 为空=提交当前 URL）
- Body：同 2.3（含回填值）
- 鉴权：是
- 测试要点：**越权改他人地址 id**（核心安全用例）、id 非法/不存在、字段回填正确性。

## 2.5 收货地址 - 删除
- URL：`GET /index.php/home/memberaddress/drop/address_id/{id}.html`（AJAX，前端 `ds_ajaxget_confirm` 弹“您确定要删除吗?”）
- 鉴权：是
- 成功：`{"code":10000,"message":"删除成功","result":""}`
- 测试要点：越权删他人地址、重复删除、删除默认地址后默认归属、删除被订单引用的地址、id 篡改。

> 测试数据：地址 id=55（张三/东莞/13800138000，默认），保留供下单使用。
