## 0. 接口测试用例要素说明

| 要素 | 说明 |
|---|---|
| 用例编号 | 模块-接口-序号，如 AUTH-CHK-001 |
| 接口模块 | 鉴权链路 |
| 接口名称 | 接口功能简称 |
| 接口URL | 完整请求路径 |
| 请求方法 | GET / POST |
| Content-Type | 请求体类型 |
| 鉴权要求 | 是否需要登录态 |
| 前置条件 | 执行本用例前需满足的条件 |

| 测试输入 | 请求参数及取值 |
| 预期结果 | 接口响应断言内容 |
| 优先级 | P0（冒烟阻塞）/ P1（核心功能）/ P2（异常边界）/ P3（兼容补充） |

## 1. 用户名可用性校验（1.1 check_member）

### 接口基础信息

| 要素 | 内容 |
|---|---|
| 接口URL | `GET /index.php/home/Login/check_member.html` |
| 请求方法 | GET |
| Content-Type | 无（Query 传参） |
| 鉴权要求 | 否 |
| 请求参数 | member_name（string，必填）、user_name（string，必填） |
| 响应格式 | 纯文本：`true`=可用，`false`=已存在 |

### 测试用例

| AUTH-CHK-002 | 正向测试 | 未注册用户名校验 | member_name=newuser_xyz88, user_name=newuser_xyz88 | 返回 `true` | P0 |
| AUTH-CHK-003 | 边界值测试 | 用户名最小长度（3位） | member_name=abc（3字符） | 返回 `true`（若未注册） | P2 |
| AUTH-CHK-004 | 边界值测试 | 用户名最大长度（15位） | member_name=abcdefghijklmno（15字符） | 返回 `true`（若未注册） | P2 |

| AUTH-CHK-006 | 边界值测试 | 用户名超过最大长度（16位） | member_name=abcdefghijklmnop（16字符） | 返回 `false` 或错误提示 | P2 |
| AUTH-CHK-007 | 异常测试 | 空值提交 | member_name=（空）, user_name=（空） | 返回 `false` 或错误提示 | P1 |

### 接口基础信息

| 要素 | 内容 |
|---|---|
| 接口URL | `POST /index.php/home/login/register.html` |
| 请求方法 | POST |
| Content-Type | `application/x-www-form-urlencoded` |
| 鉴权要求 | 否（已登录访问会 302 跳转会员中心） |
| 请求参数 | member_name（3-15位）、member_password（6-20位）、member_password_confirm（与密码一致） |

## 3. 会员登录（1.3 login）

| 要素 | 内容 |
|---|---|

| AUTH-LOG-002 | 异常测试 | 错误密码登录 | member_name=testo2o1943, member_password=wrongpwd | `{"code":10001,"message":"账号或密码错误"}` | P0 |
| AUTH-LOG-003 | 异常测试 | 不存在的账号登录 | member_name=notexist999, member_password=123456 | `{"code":10001,"message":"账号或密码错误"}` | P0 |

| AUTH-LOG-014 | 异常测试 | 密码超长（1000字符） | member_password=（1000个a） | 服务端正常处理，返回失败，无崩溃 | P3 |

## 4. 退出登录（1.4 logout）

### 接口基础信息

|---|---|

## 7. 短信找回密码（1.7 find_password）

### 接口基础信息

| 要素 | 内容 |
|---|---|
| 接口URL | `POST /index.php/home/connectsms/find_password.html` |
| 请求方法 | POST |
| Content-Type | `application/x-www-form-urlencoded` |
| 鉴权要求 | 否 |
| 请求参数 | sms_mobile（已注册手机号，11位）、sms_captcha（短信验证码，≥6位）、member_password（新密码，6-20位） |
| 响应格式 | 成功：跳转或提示重置成功；失败：dispatch_jump 错误页 |
| 前置条件 | 手机找回密码功能开启、验证码已通过 check_captcha 校验 |
